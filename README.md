# 迷案·回声

一款已有可运行原型的 AI 多人在线剧本杀网页游戏。玩家通过浏览器进入房间，阅读角色信息、搜集线索、讨论推理并投票；AI 在角色知识和剧情规则的约束下参与互动。

## 当前阶段

仓库已包含 Node.js 网页原型，代码位于 `game/`。支持单人搭配两名 AI、房间码好友局、按角色快速匹配、真人招募、AI 补位、共享证据、讨论追问、指认和复盘。新房间使用 2/3/7/4 分钟阶段上限，15–20 分钟为首次试玩目标，仍需真实玩家校准。团队在本地开发与测试，公网部署需另行配置。

## 首版目标

- 三名玩家在线进入同一房间，完成一局剧本推理。
- 支持角色卡阅读、线索搜集、讨论、投票和结算。
- 支持与 AI 剧情角色对话，回答受角色知识及剧情阶段约束。
- 探索由玩家确认设定、预览并控制发送的 AI 角色代言。
- 适配手机浏览器，同时方便在电脑上开发和测试。

首版目标已在原型中实现；自动化测试覆盖 12 项场景。实际浏览器全流程、手机适配、真实玩家时长及公网稳定性仍需进一步验收。

## 本地开发

安装 Node.js 24，无需安装额外依赖。Windows 双击 `game/start-game.cmd`，保持启动窗口开启，再访问 http://127.0.0.1:8787 。首页选择「单人试玩」，填昵称并选角色即可开始。

也可在仓库根目录运行：

```powershell
node game/server.mjs
```

运行测试：

```powershell
node --test game/game.test.mjs
```

详细局域网、8788 独立实例和临时公网启动方式见 [游戏运行说明](game/README.md)。`game/case.mjs` 依赖根目录的 [原型完整方案](迷案回声_网页剧本杀完整方案.md)，请保留文件位置。根目录方案为本地原型使用的版本；`docs/mian-huisheng/` 保留团队当前协作文档，两者尚未合并。

运行数据、日志、模型密钥、本机 Python 环境和资料暂存目录不纳入版本控制。

开发时请勿将模型 API 密钥、密码或个人配置提交到仓库。
