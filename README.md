# 迷案·回声

一款正在规划中的 AI 多人在线剧本杀网页游戏。玩家通过浏览器进入房间，阅读角色信息、搜集线索、讨论推理并投票；AI 在角色知识和剧情规则的约束下参与互动。

## 当前阶段

项目目前处于方案设计和资料整理阶段，仓库尚无可运行的游戏代码。团队先在本地开发和测试网页游戏，最终成品不考虑依赖华为云环境。具体技术栈、模型服务和部署方式将在开发中确定。

## 首版目标

- 三名玩家在线进入同一房间，完成一局剧本推理。
- 支持角色卡阅读、线索搜集、讨论、投票和结算。
- 支持与 AI 剧情角色对话，回答受角色知识及剧情阶段约束。
- 探索由玩家确认设定、预览并控制发送的 AI 角色代言。
- 适配手机浏览器，同时方便在电脑上开发和测试。

上述功能均为开发目标，尚未实现或验证。
