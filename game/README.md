# 迷案·回声 · 三人网页原型

Windows 上可双击 `start-game.cmd` 启动并打开浏览器。试玩时保持启动窗口开启；单独打开网页链接不会启动服务。也可以在项目根目录使用 Node.js 24 启动，无需安装依赖。

```powershell
node game/server.mjs
```

打开 [http://127.0.0.1:8787](http://127.0.0.1:8787)。用三个独立的浏览器配置或设备，创建房间、输入相同的房间码、各选一个角色并准备。每个浏览器配置存储一个重连凭据。

- **快速匹配**：先选角色。三名真人各选了不同角色后自动进入读本。等待时可取消并改选角色。
- **好友房**：凭房间码加入时仍由房主手动开局。两人选角并准备后，房主可以招募快速匹配队列中选择了空缺角色的真人，或添加 AI 扮演该角色。真人招齐或 AI 补位后立即开局。
- **单人试玩**：在首页点「单人试玩」，填昵称、选角色后直接读本。两名 AI 分别扮演剩余角色。
- **AI 队友**：每名队友在初谈和调查阶段各搜证及发言一次，并在投票阶段各投一票。配置模型后由模型从允许的行动里选择。模型不可用时，队友按游戏规则行动。

同一局域网跨设备试玩时，在可信网络上设置 `$env:HOST='0.0.0.0'` 再启动。其他玩家访问主机的局域网 IP 和端口 `8787`。公网运行需使用 HTTPS 反向代理，并把数据目录放在持久卷上。

快速匹配与真人招募依赖玩家访问同一服务实例。跨网络试玩需让所有玩家访问同一公网实例。排队或招募期间连续 45 秒未连接会结束等待。

新版首页的「单人试玩」选择昵称和角色后可以直接开局。新房间按 2 分钟读本、3 分钟查现场、7 分钟调查、4 分钟指认计时。满足页面上的条件并由所有真人确认后可提前进入下一阶段。调查第 5 分钟补齐证物，指认时选 1–2 条已公开的证物作为依据。复盘先展示个人选择，再展示房间票数和证据链。

做同场对照时，用不同端口与 `GAME_DATA` 启动两个实例。在旧版实例设置 `GAME_FLOW_VERSION=1` 后再建房，新版沿用默认值。记录首次取证时间、各阶段等待、在证物与讨论之间的切换次数，以及玩家能否解释其指认证据。用不知道真相的试玩者独立验证首次完成时间，避免把对照中第二次试玩的熟练度当成流程提升。

临时公网试玩使用 [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。将官方 Windows 版 `cloudflared.exe` 放在 `game/data/tools/`，再从 PowerShell 运行 `./game/start-online.ps1`。脚本启动独立的 8788 实例，房间数据和日志保存在 `game/data/online-8788/`。访问输出的 HTTPS 地址加入同一队列。执行 `./game/start-online.ps1 -Stop` 停止试玩；主机需保持开机联网，重开隧道会更换地址。

隧道服务未能分配公网地址时，在项目根目录运行 `./game/start-online.ps1 -LocalOnly` 可单独启动 [8788 本机试玩](http://127.0.0.1:8788)。如果上次的进程已退出，再运行即可恢复该实例，房间数据保留。准备重试公网时，先用 `-Stop` 停掉它，再运行启动命令。8788 和默认的 8787 是不同实例，房间码不能混用。

初谈和调查开始后，AI 会错峰搜证并发言。点「问队友」可指定一名 AI 回答，回答会出现在公开讨论中。配置模型时，提问和当前公开证物会发送到模型服务；无模型时使用本地角色回复。

服务默认把房间状态写入 `game/data/rooms.json`，支持用 `GAME_DATA` 指定独立数据文件。原型按单进程运行。启动入口会从项目根目录的《迷案回声_网页剧本杀完整方案.md》加载剧本，部署时需一并保留该文件。

AI 为可选配置。启动前提供 `AI_URL`（完整的 Chat Completions URL）、`AI_MODEL` 与 `AI_KEY` 以启用盘问和发言草稿。玩家点击盘问时，模型从当前已公开的证言或日记中选择一句，服务端只返回原文句子。发言草稿仅使用玩家主动输入的文字和表达偏好。模型缺席或请求失败时，仍可查看原始记录、领取全部证物并正常结算。可设 `GAME_MINUTE_MS` 缩短测试场次的游戏计时，正常运行请使用默认值。

实物机关、真实模型表现、三台实体设备和华为云环境需另行验收。运行时数据含玩家发言与重连凭据摘要，请保存在服务端。

运行 `node --test game/game.test.mjs` 可验证三个独立会话的权限、线索兜底、投票与重启恢复。测试只监听本机端口并使用临时目录。
